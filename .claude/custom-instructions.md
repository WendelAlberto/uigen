# Instruções Customizadas

**Para futuras instâncias Claude Code neste projeto:**

O projeto já está configurado com todas as dependências instaladas.
O servidor já está rodando em localhost:3000. Os logs estão sendo
escritos em logs.txt. Se necessário, você pode consultar o banco
de dados com o CLI 'sqlite3'. Se necessário, use o conjunto de
ferramentas mcp__playwright para iniciar um navegador e interagir
com o app.

---

**Requisito obrigatório:** Toda comunicação e documentação em português brasileiro (PT-BR).
